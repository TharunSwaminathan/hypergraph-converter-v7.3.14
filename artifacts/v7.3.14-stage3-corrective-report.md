## Source correction

The only production file changed is `src/graph/incidenceIndex.js`:

```js
setPrototypeOf() {
  throw new TypeError(`${label} is read-only.`);
},
```

The function documentation now states the existing policy explicitly: derived collection topology is read-only, while `hyperedgesById` continues to retain the original canonical hyperedge record references. Canonical records are not cloned or deep-frozen.
