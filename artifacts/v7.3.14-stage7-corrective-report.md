## Pre-fix reproduction and root cause

The real cache/request infrastructure reproduced the required sequence. Cache A/version 41 and coordinator request A were active. Rendering selected cache B/version 42 without advancing the old coordinator. A then completed as a legitimate coordinator `completed` outcome. The ambient `setComplete` accepted A, keyed it under B, repeated B activation was a no-op, and B lookup returned the exact A object.

The controlled React test reproduced the same interleaving with a transition that rendered B, activated the shared cache, and suspended while the committed A hook/coordinator stayed active. Resolving A poisoned B with an `A_ONLY` V2V result before the fix.

The root cause was not cancellation timing. The cache write API derived its key solely from mutable ambient activeGraphVersion and validated neither the producing graph version nor identity.
