# Hypergraph Converter Studio v7.3.14 — Stage 5 Corrective Evidence

## Scope and checkpoint

This corrective starts directly from Stage 5 commit `2b61a6e4f7d6764bf0796b2c265c87d0fb3ad7cd` and addresses only S5-N01: selection-driven visualization-effect recreation cleared active node drag or canvas pan state. Package version remains 7.3.13 and dependencies are unchanged.

## Pre-change runtime reproduction

`artifacts/v7.3.14-stage5-corrective-prechange.json` was captured before editing `Viz.jsx` using happy-dom, React DOM, Vite SSR, and deterministic canvas/RAF probes.

- Node `a` began at `(400, 31.2)`. After mouse-down selected it and React effects committed, mousemove requested `(520, 131.2)` but the node remained at `(400, 31.2)`.
- With a selection active, empty-canvas mouse-down cleared selection. After React effects committed, mousemove requested a `(+60,+30)` pan but translation remained `(0,0)`.

The source sequence corroborated both runtime failures: the effect depends on selection state and reconstructed `stateRef.current` with `drag:null` and `pan:null`.

## Corrective contract

The visualization effect now carries `prev.drag` and `prev.pan` only when the exact graph slice, layout, and view remain compatible. A carried drag is additionally accepted only if the dragged vertex still exists in the rebuilt position Map. Graph replacement, removed vertices, layout replacement, and view replacement therefore cancel incompatible gestures safely. Existing mouseup, mouseleave, touchend, effect cleanup, and unmount termination remain authoritative.

No selection update was removed. Node click still selects/toggles a node, ring click selects/toggles a hyperedge, and empty canvas clears selection while beginning pan.

## Corrective integration results

- Complete node gesture moved `a` by the exact requested world-coordinate delta after its selection commit.
- Selected-state and unselected-state pan gestures applied their exact requested transform deltas.
- Mouseup, mouseleave, and touchend prevented later movement and returned the static Preview to RAF idle.
- Replacing the graph while dragging a removed vertex caused no exception, stale mutation, or graph-data mutation.
- Layout change canceled active drag; view change canceled active pan.
- Original ring/node priority, Force, co-membership, LOD, resize, search, metadata, and view-isolation tests remain green.
