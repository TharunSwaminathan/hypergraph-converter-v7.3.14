## Effective deployment boundaries

Canonical launchers use strict port 5173 and 127.0.0.1. Browser storage is per origin; localhost, a different port, or another profile is separate storage. Explicit portable file transfer is supported; automatic cross-origin relocation is not. See run-dev.bat:4, run-preview.bat:4 and src/persistence/storageCoordinator.js:76.

Ollama direct transport and the optional Ollama bridge are separate from CANDY bearer-authenticated native execution. A loopback browser-facing bridge may target an operator-configured private upstream; that is not proof of same-host Ollama. CANDY is shared local session authority, not per-project server tenancy. Native executables and qualification records are operator inputs, excluded from portable source where policy requires. All concrete paths, startup variants, bounds and documentation disagreements are retained in the threat model's 13-resource table.
