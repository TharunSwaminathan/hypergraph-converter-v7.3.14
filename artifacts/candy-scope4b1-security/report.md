## Threat Model

Scope 4B1 adds a standalone, local, bounded STATIC CUDA incidence-motif executable and developer qualification transport/harness. The transport canonicalizes a Hypergraph-family incidence object, packs dense H2V rows and identity/version/device metadata, and the executable accepts only --request \<local-file\>. Native code reads and parses that bounded regular file, derives the classification table on the host, counts triples exclusively in a CUDA kernel, and returns JSON; the harness checks binding and structure and compares counts to an external CPU oracle. Production capability declarations remain SSSP-only. Evidence: candy-runtime/test/hypergraph-motif-cuda-contract.mjs:8; candy-runtime/native/hypergraph-motif-cuda/src/main.cu:53; candy-runtime/native/hypergraph-motif-cuda/src/main.cu:155; candy-runtime/native/hypergraph-motif-cuda/src/main.cu:186; candy-runtime/test/run-hypergraph-motif-cuda-qualification.mjs:49; candy-runtime/src/capabilities/capabilityRegistry.js:48.
