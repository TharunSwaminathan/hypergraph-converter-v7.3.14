# Test-gap analysis — qualified v7.3.14

Baseline: `4a2ca6ca535a4f8d78f6f6d0b61150b6fe9c0302`. With the bundled Node/Python runtimes on PATH, the unchanged suite passed **249/249 test files in 104.3 s**. The first environment run stopped at 151/249 because Python 3 was not discoverable; that was a prerequisite failure, not a source-code test failure.

Passing 249 files did not prove the live workflows. Most tests use deterministic or mocked model responses, isolated validators, source-level UI assertions, fixed port/runtime assumptions, or native CANDY contract fixtures. They do not assert the composition of production JSON Schema, qwen3:8b's actual response, repair, timeout, UI error presentation, and confirmation in one run. The result is a suite that checks many fail-closed properties but misses availability, contract coherence, and operator truthfulness.
