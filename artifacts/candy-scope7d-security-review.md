# Scope 7D substantive security review

PASS: 0 validated unresolved Critical and 0 High findings in the complete Scope 7D production delta. Automated Codex Security was NOT RUN; no automated seal is claimed. This is a manual source/data-flow review backed by the complete 301-file source and extracted suites, focused adversarial tests and 27 isolated native Chrome cases. It is not a universal certification of the browser, local service or model outputs.

| Surface | Reviewed control and evidence |
|---|---|
| SSRF, endpoint/provider/transport confusion | Exact existing credential-free loopback endpoint allowlist, URL parsing before network/storage, no redirect, arbitrary host/path/port/scheme/query/fragment rejected, no automatic transport/cloud fallback. Model client and bridge implementation unchanged. |
| Credentials and stored secrets | Profile/record exact fields and bounded plain data reject headers/tokens/extra fields. GET has credentials omit and no body/authorization headers; server error body is never echoed. Network exceptions are redacted. No credential configuration added. |
| Hostile names and unsafe rendering | Existing bounded model-name grammar, canonical string/unique inventory validation, exact remembered-model membership, no shell interpolation, React text rendering. Numeric/noncanonical/command-character names and malformed inventories rejected. |
| Cache/liveness confusion and missing models | CONFIGURED is not CONNECTED; fresh successful discovery is mandatory. Historical time/availability is not liveness. Missing model stops with no substitution. Healthy background checks preserve active inference; failures invalidate connection. |
| Stale writers and model-response races | Native transaction CAS, generation/AbortController, serialized local preference writes, post-probe revision read, pre-request assertReady, obsolete hook ownership checks. Cross-tab stale write and A→B late-response tests pass; no foreign rebase. |
| Timer/probe exhaustion and storms | Four attempts, bounded delays/timeouts/response size/model count, one scheduled timer per coordinator, six-second atomic shared lease. Cancel/unmount/Forget clear timers and abort; exhaustion has no retry timer. A browser-suspended request can overlap after lease expiry; stale results still cannot grant authority. Not a global distributed rate-limit guarantee. |
| Migration/forget resurrection | Database v3→v4 adds one store; native reconstructed-v3 graph/source/memory records preserved. Legacy selection migrates only as unverified auto-OFF draft. Tombstones block re-seeding; general settings persist public defaults rather than private connection hints. Explicit Forget removes the legacy input key. A foreign stale profile cannot resurrect the tombstone. |
| Atomicity and storage failure | Existing transaction completion-only receipt reused. CAS/future-schema and held-commit tests pass; incompatible/corrupt records remain preserved, and failed durable intent writes are reported rather than silently acknowledged. Project deletion leaves the application profile; application clear atomically tombstones connection intent. |
| Prompt contamination, cross-project memory | Probe receives no prompt, graph or memory. Actual first/reload/reopen qwen requests receive newly built current bounded project memory through unchanged 7C context code. Project-owned memory is independent of application connection settings. |
| Automatic mutation/action replay | No pending Apply/delete/parser/CUDA/confirmation is stored in the profile or resumed. Mutation executors, deterministic authority, confirmation, stale graph checks, Analyze/Apply separation, parser review/Run/Apply, Runtime auth and CUDA boundaries remain byte-identical and their retained tests pass. |
| Arbitrary process execution/cloud requirement | No process launch, shell invocation, download, model pull or cloud provider in the product delta. Qualification tooling launches only its own isolated Chrome and HTTP/Vite servers; actual Ollama was already running and was not stopped. |
| Package/private state | Clean/populated ZIPs identical, every archived file equals frozen source, all 15 proposed paths included; synthetic endpoint/history/credential/native/cache/model-weight markers excluded. No runtime connection profile is required in Git-free tests/builds. |
