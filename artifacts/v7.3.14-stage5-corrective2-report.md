## Pre-change runtime reproduction

`artifacts/v7.3.14-stage5-corrective2-prechange.json` was captured before production editing using happy-dom, React DOM, Vite SSR, and deterministic canvas/RAF probes. Canvas mouseup and mouseleave were deliberately omitted.

- Stale pan: a held movement established translation `(40,20)`. A later mousemove with `buttons=0` incorrectly changed it to `(80,50)`, a further 50 px.
- Stale drag: a held movement placed node `a` at `(460,71.2)`. A later mousemove with `buttons=0` incorrectly moved it to `(520,111.2)`, a further 72.111 px.

The source root cause matched the runtime evidence: `onMove()` trusted `stateRef.current.drag` or `.pan` without checking the current mouse-button state, and outside-canvas release delivery could bypass the canvas-local terminators.

## Corrective contract

The patch is defense in depth:

- Mouse movement with active drag/pan and `buttons===0` clears both transient gestures before any node-position or transform mutation.
- The guard is mouse-specific; touch events are not canceled for lacking `MouseEvent.buttons`.
- One stable React effect installs window-level `mouseup` and `blur` termination and removes both listeners on unmount.
- Existing canvas `mouseup` and `mouseleave` cancellation remains.
- Existing `touchend` remains and `touchcancel` now uses the same termination path.
- Termination changes only transient `drag`/`pan` fields. It does not reset selection, transform, zoom, node positions, layout, view, or graph.
